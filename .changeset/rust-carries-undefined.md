The MiniJinja adapter and its Rust runtime (the `barefootjs` crate) now carry JS `undefined` apart from `null` (`spec/js-undefined-value.md`, rollout step U3). `JsValue` gains an `Undefined` variant, which is minijinja's own undefined; host nil (`JsValue::Null`, minijinja's `none`, a `serde_json` `null`) is JS `null`. A missing field, an out-of-range index, `.at()` / `.find()` with no result, the `undefined` identifier (`bf.undefined` in a template), `?.` over a nullish receiver and an omitted declared prop read as `undefined`. `String()` / template literals / `+` print it as `"undefined"` (`null` as `"null"`), `Number()` and arithmetic read it as `NaN` (`null` as `0`; an unproven `-` / `*` takes the new `bf.sub` / `bf.mul`), `x === null` / `x === undefined` are strict tests (`bf.is_null` / `bf.is_undefined`; `x == null` is `bf.is_nullish`), `JSON.stringify` and the `bf-p` / scope-comment payloads drop an `undefined` member and write an `undefined` element as `null`, `includes` / `indexOf` tell the two apart, a sort puts `undefined` last, and an optional method argument (`slice` end, `join` / `split` separator, `padStart` pad, `at` index, …) takes its default only when it is omitted or `undefined`. `searchParams().get(k)` of an absent key is JS `null` (`none`). A destructure default now applies only to an absent or `undefined` prop: an explicit `null` keeps `null` (`derive_stash_from_defaults` and `render_child`'s seed). The crate adds `barefootjs::Opt<T>` (absent / undefined / null / value, `Default` = absent) with `Serialize` / `Deserialize` impls for typed host props, and `JsValue::is_undefined` / `is_null` / `is_nullish`.

Migration: a host that passed `JsValue::Null` (or a JSON `null`) to mean "unset" now gets JS `null` semantics (`'btn ' + c` renders `btn null`, and a destructure default no longer applies). To leave a prop unset, omit its key; to pass a prop that is present and `undefined`, pass `JsValue::Undefined`, or use `Opt<T>` (`#[serde(default, skip_serializing_if = "Opt::is_omitted")]`) in a typed props struct. A host matching exhaustively on `JsValue` needs an `Undefined` arm.
