"@barefootjs/pebble": minor

The Pebble adapter and its Java runtime (`dev.barefootjs.pebble`, the `barefootjs-pebble-runtime` jar) now carry JS `undefined` apart from `null` (`spec/js-undefined-value.md`, rollout step U7). Java's `null` is JS `null`; JS `undefined` is `dev.barefootjs.pebble.Undefined.INSTANCE` (new `Undefined`), a singleton whose `toString()` is `""` and which Pebble's `{% for %}` iterates as empty. A missing key, an out-of-range index, `.at()` / `.find()` with no result, the `undefined` identifier (`bf.undefined()` in a template), `?.` over a nullish receiver (`bf.get_opt`), an optional or untyped field read (`bf.get` in place of Pebble's `.k`) and an omitted declared prop read as `Undefined`. `String()` / template literals / `+` print it as `"undefined"` (`null` as `"null"`), `Number()` and arithmetic read it as `NaN` (`null` as `0`; an unproven `-` / `*` is the runtime's `bf.sub` / `bf.mul`, and `div` / `mod` coerce through JS ToNumber), `x === null` / `x === undefined` are strict tests (`bf.is_null` / `bf.is_undefined`; `x == null` is `bf.is_nullish`), `??` coalesces both (`bf.coalesce`), `JSON.stringify` and the `bf-p` / scope-comment payloads drop an `undefined` member and write an `undefined` element as `null` (`Bf.json`), `includes` / `indexOf` tell the two apart, a sort puts `undefined` last, and an optional method argument (`slice` end, `join` / `split` separator, `split` limit, `padStart` pad, `endsWith` position, `flat` depth) takes its default only when it is omitted or `undefined`. A destructure default now applies only to an absent or `undefined` prop: an explicit `null` keeps `null` (`DeriveStashFromDefaults.derive` / `rootVars`). The `bf` object adds `undefined`, `is_undefined` / `is_null` / `is_nullish` and `get_opt`; `Bf.json` returns `Undefined` (printing nothing) for an `undefined` argument.

Migration: a host that passed `null` to mean "unset" now gets JS `null` semantics (`'btn ' + c` renders `btn null`, and a destructure default no longer applies). To leave a prop unset, leave its key out of the props map; to pass a prop that is present and `undefined`, put `Undefined.INSTANCE`. `Undefined` is an ordinary Java object: host code that tests a value it got back from the runtime should use `Undefined.isNullish()` / `isUndefined()` rather than `== null`, and must not hand it to Gson or Jackson, which do not follow `JSON.stringify` for it; `Bf.json` does.
