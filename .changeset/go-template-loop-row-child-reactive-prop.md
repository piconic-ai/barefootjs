A component inside a `.map()` loop row whose body is a single child component now gets its signal- and memo-derived props at SSR, whether it is nested in that component's forwarded children (`<Chip><Mark on={highlight()}>…</Mark></Chip>`) or is the row component itself over a memo-derived list (`<Chip on={highlight()}>`). These props used to be dropped from the generated constructor, so the component rendered with the prop's zero value (for example, an attribute guarded by the prop went missing), with no diagnostic. A component nested in the forwarded children also receives props that read the row item (`<Mark tone={o.tone}>`) per row instead of the zero value.

A `/* @client */` prop on a component inside a loop row — nested in a row component's forwarded children or in an element row (`<li><Mark tone={/* @client */ o.tone} /></li>`) — is now rendered at SSR whenever it can be lowered, as it already was outside a loop, instead of being dropped. One that can't be lowered is still left to the client without a diagnostic.

A row-independent prop on either component that still cannot be lowered to a Go value now refuses with `BF101` instead of being dropped silently — but only when it is SSR data the component should have received: a prop whose name maps to a Go field, or a hyphenated one (`data-x`) that the component collects through a `...rest` spread. The following stay out of the constructor without a diagnostic, as they do outside a loop: a `/* @client */` prop that can't be lowered (the escape; one that can is now rendered at SSR instead of being dropped), `children` (delivered through the forwarded-children template), `ref`, event handlers (`on` followed by an uppercase letter), any other function-valued prop (an inline arrow or function, a signal setter, a local function or a const holding one), a hyphenated name on a component with no rest bag, and an imported value (`import { formatTone } from './format'`, a default import, or a member of a namespace import such as `utils.formatTone`) unless the component declares that prop as a primitive or an array, which can't hold a function. Props named like `only` or `once` are data, not event handlers: they are lowered, delivered per row, or refused like any other prop.
